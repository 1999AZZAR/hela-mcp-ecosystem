Architectural Efficiency Principles

1. Structured Memory Over Raw Logs

Always record architectural decisions and task completion milestones to hela-genome so downstream turns don't consume context parsing thousands of log lines.

2. Structural Dumps Over Screenshots

For mobile (hela-receptor) and browser (hela-cytosol), inspect XML and accessibility trees for element location; reserve visual screenshots for final verification.

3. Fail-Fast Doctor Diagnostics

Always verify runtime and binary prerequisites via ./setup.sh doctor before spawning long-running cross-server automation pipelines.

4. Subshell RTK Command Isolation

Execute shell operations through hela-nucleus with RTK token filtering to strip redundant stdout noise and escape subshell pollution.

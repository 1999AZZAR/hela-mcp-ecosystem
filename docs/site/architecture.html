System Specification

Cellular Architecture & Dual-Backbone

The HeLa MCP Ecosystem organizes 10 specialized servers into a cohesive, deterministic organism governed by dual-backbone coordination and standard Model Context Protocol (MCP) JSON-RPC 2.0 stdio.

Foundation

The Dual-Backbone Coordination Model

🧬 HeLa Mitosis chaining-mcp-server

Cognitive Orchestration Backbone: Responsible for intelligent task routing, iterative step-by-step reasoning via sequentialthinking, task decomposition, and dynamic peer MCP server discovery.

Entrypoint: dist/index.js • 18 Tools • Scope: Core
🧠 HeLa Genome Project-Guardian-mcp-server

Persistent State Backbone: Living SQLite knowledge graph (memory.db) with full-text FTS5 search, entity-relation tracking, decision memory, cross-session context restoration, and prompt injection defense.

Entrypoint: dist/index.js • 34 Tools • Scope: Core
Every profile in HeLa mounts Mitosis and Genome, ensuring any dispatched organelle retains full reasoning and persistent memory context.

In Recognition of Henrietta Lacks

The HeLa MCP Ecosystem is named in respectful recognition of Henrietta Lacks (1920–1951) and the immortal scientific legacy of HeLa cells, which transformed global biomedical research. In this architecture, HeLa represents modular specialization, deterministic replicability, and software longevity.

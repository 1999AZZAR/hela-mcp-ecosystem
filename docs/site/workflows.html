Workflows

Standardized recipes combining cells into automated pipelines. Each lists the invocation sequence, the profiles it fits, and where state lands.

A — Autonomous Feature Engineering

Profiles: dev-workspace, headless-server. Full-stack change with restored context and tested output.

  1. Restore constraints. hela-genome:get_session_context — architecture and dependencies from memory.db.
  2. Decompose. hela-mitosis:analyze_with_sequential_thinking — atomic implementation steps.
  3. Edit. hela-membrane:write_file — minimal, production-ready changes.
  4. Test. hela-nucleus:execute_command — e.g. npm test.
  5. Commit memory. hela-genome:add_observation — record completion and relations.

B — Deep Research & Synthesis

Profiles: research, dev-workspace. Literature → live docs → summarized trade-offs → stored knowledge.

  1. Survey. hela-enzyme:research_brief — one-call Google + Wikipedia fan-out (preferred over manual chaining).
  2. Scrape. hela-cytosol:browser_navigate → browser_get_page_markdown — structured extraction from target URLs.
  3. Synthesize. hela-mitosis:llm_summarize — comparative analysis.
  4. Store. hela-genome:create_entity + add_observation — entities and findings in memory.db.
  5. Publish. hela-membrane:write_file — markdown summary under docs/.

C — UI Design Synthesis & Verification

Profiles: web-devops, dev-workspace. Tokens → components → live render → DOM verification.

  1. Tokenize. hela-phenotype:generate_tokens / palette_fetch — OKLCH tokens, type scale, Tailwind config.
  2. Build. hela-membrane:write_file — component code and tailwind.config.js.
  3. Serve. hela-nucleus:execute_command — local dev server.
  4. Verify. hela-cytosol:browser_navigate → browser_screenshot — AX-tree check and rendered capture.
  5. Record. hela-genome:add_observation — milestone and snapshot reference.

D — Mobile Device Automation & UI Testing

Profiles: android-testing, all. Hardware bridge with token-efficient XML inspection (no screenshot loops).

  1. Discover. hela-receptor:device_list — ADB devices.
  2. Attach. hela-receptor:start_session — control stream.
  3. Inspect. hela-receptor:ui_dump — structural hierarchy.
  4. Act. hela-receptor:tap / input_text — touch and form automation.
  5. Record. hela-genome:add_observation — results in the memory graph.

E — Interactive PTY Orchestration

Profiles: dev-workspace, headless-server. Long builds, REPLs, and regex-driven automation.

  1. Spawn. hela-ribosome:agent_spawn — routed opencode agent (or session_spawn for raw PTY).
  2. Stream. hela-ribosome:session_read — bounded stdout/stderr chunks.
  3. Hook. hela-ribosome:session_hook — regex triggers with auto-response.
  4. Close. hela-ribosome:session_close — graceful teardown.
  5. Record. hela-genome:add_observation — logs and exit status.

F — Autonomous Blender 3D Modeling

Profiles: 3d-modeling, all. Prompt → geometry → render → asset.

  1. Plan. hela-plastid:generate_modeling_plan — phased procedural scripts.
  2. Execute. hela-plastid:execute_blender_code — geometry, materials, lighting.
  3. Render. hela-plastid:render_output — camera snapshot.
  4. Save. hela-plastid:save_blend — binary .blend under assets/.
  5. Record. hela-genome:add_observation — asset metadata and render path.
